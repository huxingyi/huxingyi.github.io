Examples

Fruit — Banana
  1. Draw five nodes in a circle (cut face shape)
  2. Right-click part → Convert to Cut Face
  3. Draw a tube-shaped part on canvas
  4. Double-click tube to select it in Parts list
  5. Open part properties → select the Cut Face
↓banana.ds3
Clothes — Hat
  1. Draw five spine parts on canvas
  2. Select all → right-click → Convert to Stitching Line
  3. Right-click → Make group
  4. Open group properties → check Back closed
  5. Set Target Segments to 7
↓hat.ds3
Animals — Dog
  1. Photograph the dog from the front and side
  2. File → Change Background Image → load both photos
  3. Draw nodes tracing the reference image
  4. Select all parts → open properties → choose texture
↓dog.ds3
